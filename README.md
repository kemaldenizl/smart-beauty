## Kurulum

Projeyi yerelde çalıştırmak için:

```bash
npm install
npm run dev
```

Uygulama varsayılan olarak localhost:3000 adresinde çalışır:

```text
http://localhost:3000
```

Eğer `3000` portu doluysa Next.js otomatik olarak uygun başka bir port seçebilir.
